# All Mover

Marketing landing page for **All Mover**, a Vermont agri-tourism app site. Static HTML/CSS with Bootstrap: hero, feature sections, store badges, and social links.

> Note: `README.txt` and `OFL.txt` belong to the bundled **Baloo Bhaijaan 2** font license, not the project docs.

## Stack

- HTML5
- CSS (`allmoverstyle.css`)
- Bootstrap 5.3
- Local assets (logos, QR codes, store badges)

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure

| Path | Role |
|---|---|
| `index.html` | Main landing page |
| `allmoverstyle.css` | Custom styles |
| `bootstrap-5.3.3-dist/` | Bootstrap assets |
| `font/` / `static/` | Font files |
